Two lines to my past self: one warning about a single concrete moment — taking the car keys at 2 a.m. outside the Blue Note — and one sentence on what that moment cost and what changed because of it. The program writes the two-line entry to `/output/entry.txt` (UTF-8, under 280 characters).

## Run it

```sh
python3 main.py
```
